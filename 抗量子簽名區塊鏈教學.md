### 3.2 抗量子算法數學基礎

#### 3.2.1 格基密碼學（Lattice-based）
```
數學問題：學習帶錯誤問題（LWE）和短整數解問題（SIS）

代表算法：Dilithium, Kyber

優勢：
✓ 高效能
✓ 簡單的數學結構
✓ 可證明安全性

私鑰示例（簡化）：
s = [s₁, s₂, ..., sₙ] ∈ Zqⁿ（小係數多項式向量）

公鑰生成：
A = 隨機矩陣 ∈ Zqⁿˣⁿ
t = As + e  （其中 e 是小誤差向量）
公鑰 = (A, t)
```

#### 3.2.2 哈希基密碼學（Hash-based）
```
數學基礎：抗碰撞哈希函數的單向性

代表算法：SPHINCS+, XMSS

優勢：
✓ 安全性完全基於哈希函數
✓ 保守、可信賴
✓ 無數學假設（只依賴哈希安全性）

劣勢：
✗ 簽名大小較大
✗ 簽名生成較慢

Merkle 樹結構：
        Root (公鑰)
       /    \
      H01    H23
     / \    / \
    H0 H1  H2 H3  ← 一次性簽名公鑰
    |  |   |  |
   SK0 SK1 SK2 SK3 ← 一次性私鑰
```

#### 3.2.3 多變量密碼學（Multivariate）
```
數學問題：求解多變量二次方程組（MQ 問題）

代表算法：Rainbow（已被破解，2022），GeMSS

系統示例：
P(x₁,...,xₙ) = (p₁(x), p₂(x), ..., pₘ(x))
其中每個 pᵢ 是二次多項式

狀態：許多方案已被攻破，需謹慎使用
```

#### 4.1.2 算法流程

**密鑰生成**：
```
1. 選擇隨機種子 ρ, K
2. 生成矩陣 A ∈ Rq^(k×l) 從 ρ
3. 選擇小向量 s1 ∈ Sl^η, s2 ∈ Sk^η
4. 計算 t = As1 + s2
5. 公鑰 pk = (ρ, t1)，私鑰 sk = (ρ, K, tr, s1, s2, t0)
```

**簽名生成**：
```
1. 計算消息哈希 μ = H(tr || M)
2. 選擇隨機向量 y
3. 計算 w = Ay
4. 計算挑戰 c = H(μ || w1)
5. 計算響應 z = y + cs1
6. 如果 ||z|| 太大或 ||w - cs2|| 太大，重新開始
7. 簽名 σ = (c, z, h)
```

**簽名驗證**：
```
1. 計算 w' = Az - ct (使用公鑰)
2. 計算 c' = H(μ || w'1)
3. 檢查 c' = c 且 ||z|| < γ1 - β
```

#### 4.1.3 Python 實現示例（使用 pqcrypto 庫）

```python
from pqcrypto.sign.dilithium3 import generate_keypair, sign, verify

class DilithiumBlockchainSigner:
    """抗量子區塊鏈簽名器"""

    def __init__(self):
        self.public_key = None
        self.secret_key = None

    def generate_keys(self):
        """生成 Dilithium 密鑰對"""
        self.public_key, self.secret_key = generate_keypair()
        return {
            'public_key': self.public_key.hex(),
            'address': self.derive_address(self.public_key)
        }

    def derive_address(self, public_key):
        """從公鑰推導區塊鏈地址"""
        import hashlib
        # 使用 SHA3-256 哈希公鑰
        hash_obj = hashlib.sha3_256(public_key)
        # 取前 20 字節作為地址
        return '0x' + hash_obj.hexdigest()[:40]

    def sign_transaction(self, transaction_data):
        """簽署交易"""
        # 序列化交易數據
        message = self._serialize_transaction(transaction_data)

        # 生成簽名
        signature = sign(message, self.secret_key)

        return {
            'transaction': transaction_data,
            'signature': signature.hex(),
            'public_key': self.public_key.hex()
        }

    def verify_transaction(self, signed_tx):
        """驗證交易簽名"""
        message = self._serialize_transaction(signed_tx['transaction'])
        signature = bytes.fromhex(signed_tx['signature'])
        public_key = bytes.fromhex(signed_tx['public_key'])

        try:
            verify(signature, message, public_key)
            return True
        except Exception as e:
            print(f"驗證失敗: {e}")
            return False

    def _serialize_transaction(self, tx_data):
        """序列化交易數據（JSON 排序）"""
        import json
        return json.dumps(tx_data, sort_keys=True).encode('utf-8')


# 使用示例
if __name__ == "__main__":
    # 創建簽名器
    signer = DilithiumBlockchainSigner()

    # 生成密鑰對
    keys = signer.generate_keys()
    print(f"地址: {keys['address']}")
    print(f"公鑰大小: {len(bytes.fromhex(keys['public_key']))} bytes")

    # 創建並簽署交易
    transaction = {
        'from': keys['address'],
        'to': '0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb0',
        'value': 100,
        'nonce': 1,
        'timestamp': 1699999999
    }

    signed_tx = signer.sign_transaction(transaction)
    print(f"簽名大小: {len(bytes.fromhex(signed_tx['signature']))} bytes")

    # 驗證簽名
    is_valid = signer.verify_transaction(signed_tx)
    print(f"簽名有效: {is_valid}")
```

## <a name="架構設計"></a>5. 抗量子區塊鏈架構設計

### 5.1 混合密碼學方案（Hybrid Approach）

在過渡期間，建議採用混合方案：

```
簽名 = Classical_Signature || PQ_Signature
驗證 = Verify(Classical_Signature) AND Verify(PQ_Signature)
```

**優勢**：
- 向後兼容現有系統
- 雙重安全保障
- 逐步遷移路徑

**Python 實現**：
```python
import hashlib
from ecdsa import SigningKey, SECP256k1
from pqcrypto.sign.dilithium3 import generate_keypair, sign, verify

class HybridBlockchainSigner:
    """混合經典-量子簽名器"""

    def __init__(self):
        # 經典密鑰（ECDSA）
        self.classical_sk = SigningKey.generate(curve=SECP256k1)
        self.classical_pk = self.classical_sk.get_verifying_key()

        # 後量子密鑰（Dilithium）
        self.pq_pk, self.pq_sk = generate_keypair()

    def sign_hybrid(self, message):
        """生成混合簽名"""
        message_bytes = message.encode('utf-8')

        # 經典簽名
        classical_sig = self.classical_sk.sign(message_bytes)

        # 後量子簽名
        pq_sig = sign(message_bytes, self.pq_sk)

        # 組合簽名
        return {
            'classical': classical_sig.hex(),
            'post_quantum': pq_sig.hex(),
            'classical_pk': self.classical_pk.to_string().hex(),
            'pq_pk': self.pq_pk.hex()
        }

    def verify_hybrid(self, message, hybrid_sig):
        """驗證混合簽名"""
        message_bytes = message.encode('utf-8')

        # 驗證經典簽名
        from ecdsa import VerifyingKey
        classical_pk = VerifyingKey.from_string(
            bytes.fromhex(hybrid_sig['classical_pk']),
            curve=SECP256k1
        )
        try:
            classical_pk.verify(
                bytes.fromhex(hybrid_sig['classical']),
                message_bytes
            )
            classical_valid = True
        except:
            classical_valid = False

        # 驗證後量子簽名
        try:
            verify(
                bytes.fromhex(hybrid_sig['post_quantum']),
                message_bytes,
                bytes.fromhex(hybrid_sig['pq_pk'])
            )
            pq_valid = True
        except:
            pq_valid = False

        # 兩者都必須有效
        return classical_valid and pq_valid

# 使用示例
signer = HybridBlockchainSigner()
message = "Transfer 100 tokens to 0xABC..."
hybrid_sig = signer.sign_hybrid(message)
is_valid = signer.verify_hybrid(message, hybrid_sig)
print(f"混合簽名驗證: {is_valid}")
```

### 5.3 交易結構設計

```python
from dataclasses import dataclass
from typing import Optional
import json

@dataclass
class QuantumResistantTransaction:
    """抗量子交易結構"""

    # 基本字段
    nonce: int
    sender: str  # 從 PQ 公鑰派生
    receiver: str
    value: int
    data: Optional[bytes]
    timestamp: int

    # 簽名字段
    signature_algorithm: str  # 'dilithium3', 'falcon512', 等
    signature: bytes
    public_key: bytes

    # 混合模式（可選）
    classical_signature: Optional[bytes] = None

    # Gas 和費用
    gas_limit: int = 21000
    gas_price: int = 1000000000  # wei

    def to_bytes(self) -> bytes:
        """序列化為字節（用於簽名）"""
        tx_dict = {
            'nonce': self.nonce,
            'sender': self.sender,
            'receiver': self.receiver,
            'value': self.value,
            'data': self.data.hex() if self.data else '',
            'timestamp': self.timestamp,
            'gas_limit': self.gas_limit,
            'gas_price': self.gas_price
        }
        return json.dumps(tx_dict, sort_keys=True).encode('utf-8')

    def hash(self) -> str:
        """計算交易哈希（使用 SHA3-256）"""
        import hashlib
        return hashlib.sha3_256(self.to_bytes()).hexdigest()

    def size(self) -> int:
        """計算交易大小（字節）"""
        base_size = len(self.to_bytes())
        sig_size = len(self.signature)
        pk_size = len(self.public_key)
        classical_size = len(self.classical_signature) if self.classical_signature else 0
        return base_size + sig_size + pk_size + classical_size
```

### 5.4 區塊結構優化

```python
@dataclass
class QuantumResistantBlock:
    """抗量子區塊結構"""

    # 區塊頭
    version: int
    previous_hash: str  # SHA3-256
    timestamp: int
    height: int

    # Merkle 根
    transactions_root: str
    state_root: str
    receipts_root: str

    # 共識字段
    validator: str  # PQ 公鑰派生地址
    validator_signature: bytes  # Dilithium 簽名
    validator_pubkey: bytes

    # 交易數據
    transactions: list[QuantumResistantTransaction]

    # 優化：簽名聚合（如果算法支持）
    aggregated_signatures: Optional[bytes] = None

    def calculate_merkle_root(self) -> str:
        """計算交易 Merkle 樹根"""
        import hashlib

        if not self.transactions:
            return '0' * 64

        # 使用 SHA3-256
        tx_hashes = [tx.hash() for tx in self.transactions]

        while len(tx_hashes) > 1:
            if len(tx_hashes) % 2 == 1:
                tx_hashes.append(tx_hashes[-1])  # 複製最後一個

            new_level = []
            for i in range(0, len(tx_hashes), 2):
                combined = tx_hashes[i] + tx_hashes[i+1]
                hash_obj = hashlib.sha3_256(combined.encode())
                new_level.append(hash_obj.hexdigest())

            tx_hashes = new_level

        return tx_hashes[0]
```

class QuantumResistantBlockchain:

        genesis_pk, genesis_sk = generate_keypair()

        genesis_block = QuantumResistantBlock(
            version=1,
            previous_hash='0' * 64,
            timestamp=int(time.time()),
            height=0,
            transactions_root='0' * 64,
            state_root='0' * 64,
            receipts_root='0' * 64,
            validator='genesis',
            validator_signature=b'',
            validator_pubkey=genesis_pk,
            transactions=[]
        )

        self.chain.append(genesis_block)

    def add_transaction(self, transaction: QuantumResistantTransaction) -> bool:
        """添加交易到待處理池"""
        # 驗證簽名

            print("交易簽名無效")
            return False

        # 驗證餘額（簡化版）

        self.pending_transactions.append(transaction)
        return True

    def verify_transaction_signature(self, tx: QuantumResistantTransaction) -> bool:
        """驗證交易簽名"""
        message = tx.to_bytes()

        try:
            if tx.signature_algorithm == 'dilithium3':
                verify(tx.signature, message, tx.public_key)
                return True
            else:
                print(f"不支持的簽名算法: {tx.signature_algorithm}")
                return False
        except Exception as e:
            print(f"簽名驗證失敗: {e}")
            return False

    def check_balance(self, address: str, amount: int) -> bool:
        """檢查賬戶餘額（簡化版）"""
        # 實際實現需要維護狀態樹
        balance = self.get_balance(address)
        return balance >= amount

    def get_balance(self, address: str) -> int:
        """獲取賬戶餘額"""
        balance = 0

        for block in self.chain:
            for tx in block.transactions:
                if tx.sender == address:
                    balance -= tx.value
                if tx.receiver == address:
                    balance += tx.value

        # 加上待處理交易
        for tx in self.pending_transactions:
            if tx.sender == address:
                balance -= tx.value

        return balance

    def mine_block(self, miner_address: str, miner_sk, miner_pk):
        """挖掘新區塊（簡化版 PoW）"""
        # 創建挖礦獎勵交易
        reward_tx = self.create_reward_transaction(miner_address, miner_sk, miner_pk)

        # 包含待處理交易
        transactions = self.pending_transactions[:100]  # 限制 100 筆
        transactions.append(reward_tx)

        # 創建新區塊
        previous_block = self.chain[-1]
        new_block = QuantumResistantBlock(
            version=1,
            previous_hash=self.hash_block(previous_block),
            timestamp=int(time.time()),
            height=len(self.chain),
            transactions_root='',
            state_root='',
            receipts_root='',
            validator=miner_address,
            validator_signature=b'',
            validator_pubkey=miner_pk,
            transactions=transactions
        )

        # 計算 Merkle 根
        new_block.transactions_root = new_block.calculate_merkle_root()

        # 簽署區塊
        block_data = self.serialize_block_header(new_block)
        new_block.validator_signature = sign(block_data, miner_sk)

        # 添加到鏈
        self.chain.append(new_block)

        # 清除已處理的交易
        self.pending_transactions = self.pending_transactions[100:]

        print(f"區塊 #{new_block.height} 已挖掘")
        return new_block

    def create_reward_transaction(self, miner_address, miner_sk, miner_pk):
        """創建挖礦獎勵交易"""
        reward_tx = QuantumResistantTransaction(
            nonce=0,

    def hash_block(self, block: QuantumResistantBlock) -> str:
        """計算區塊哈希"""
        block_data = self.serialize_block_header(block)
        return hashlib.sha3_256(block_data).hexdigest()

    def serialize_block_header(self, block: QuantumResistantBlock) -> bytes:
        """序列化區塊頭"""
        import json
        header = {
            'version': block.version,
            'previous_hash': block.previous_hash,
            'timestamp': block.timestamp,
            'height': block.height,
            'transactions_root': block.transactions_root,
            'state_root': block.state_root,
            'receipts_root': block.receipts_root,
            'validator': block.validator
        }
        return json.dumps(header, sort_keys=True).encode('utf-8')

    def validate_chain(self) -> bool:
        """驗證整條鏈"""
        for i in range(1, len(self.chain)):
            current = self.chain[i]
            previous = self.chain[i-1]

            # 驗證前一個區塊哈希
            if current.previous_hash != self.hash_block(previous):
                print(f"區塊 #{i} 的前一個哈希無效")
                return False

            # 驗證區塊簽名

                return False

            for tx in current.transactions:
                if not self.verify_transaction_signature(tx):
                    print(f"區塊 #{i} 包含無效交易")

    def create_election(self, admin_sk, admin_pk, election_info):
        """創建選舉（管理員 PQ 簽名）"""
        election_id = hashlib.sha3_256(
            json.dumps(election_info).encode()
        ).hexdigest()

        self.elections[election_id] = {
            'info': election_info,
            'votes': {},
            'status': 'active'
        }

        # 記錄到區塊鏈
        tx_data = {
            'type': 'create_election',
            'election_id': election_id,
            'info': election_info
        }

        tx = self.create_signed_transaction(
            admin_sk, admin_pk, tx_data
        )
        self.blockchain.add_transaction(tx)

        return election_id

    def cast_vote(self, voter_sk, voter_pk, election_id, choice):
        """
        投票（匿名性 + PQ 簽名）
        使用零知識證明 + PQ 簽名組合
        """
        voter_address = self.derive_address(voter_pk)

        # 檢查是否已投票
        if voter_address in self.elections[election_id]['votes']:
            raise Exception("已經投過票")

        # 創建投票承諾（隱藏實際選擇）
        vote_commitment = self.create_vote_commitment(choice, voter_address)

        # 投票交易
        vote_data = {
            'type': 'cast_vote',
            'election_id': election_id,
            'commitment': vote_commitment,
            'timestamp': int(time.time())
        }

        tx = self.create_signed_transaction(
            voter_sk, voter_pk, vote_data
        )
        self.blockchain.add_transaction(tx)

        # 記錄投票
        self.elections[election_id]['votes'][voter_address] = vote_commitment

    def create_vote_commitment(self, choice, voter_address):
        """創建投票承諾（隱藏選擇）"""
        import hashlib
        import secrets

        # 生成隨機 nonce

        # 承諾 = Hash(choice || voter || nonce)
        commitment = hashlib.sha3_256(
            f"{choice}{voter_address}".encode() + nonce

        return {
            'commitment': commitment,
